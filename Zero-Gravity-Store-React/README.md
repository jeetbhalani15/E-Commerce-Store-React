# Zero Gravity Store

A modern e-commerce platform for video games built with React.

## 🚀 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/yourusername/zero-gravity-store.git
cd zero-gravity-store
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Set up environment variables:
```bash
cp .env.example .env
# Edit .env with your values
```

4. Start development server:
```bash
npm start
# or
yarn start
```

## 🏗️ Production Deployment

1. Build the application:
```bash
npm run build
# or
yarn build
```

2. The build folder is ready to be deployed.
   - You can serve it with a static server:
     ```bash
     npm install -g serve
     serve -s build
     ```
   - Or deploy to platforms like Vercel, Netlify, or AWS Amplify

## 🔧 Environment Variables

- `REACT_APP_JWT_SECRET`: Your JWT secret key
- `REACT_APP_API_URL`: Your API endpoint
- `REACT_APP_ENV`: Environment (development/production)

## 📦 Features

- Modern React with Hooks
- React Router for navigation
- JWT authentication
- Responsive design
- Game catalog with filtering
- Shopping cart functionality
- Wishlist management
- Secure checkout process

## 🛠️ Tech Stack

- React 18
- React Router 6
- Axios for API calls
- JWT for authentication
- React Icons
- React Toastify for notifications
- React Spinners for loading states
